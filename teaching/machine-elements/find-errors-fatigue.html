Problem 3-14 — submitted by A. Student

A machined AISI 1040 HR link (Su = 620 MPa, Sy = 410 MPa, ~40 mm section, 99% reliability) has a well-rounded fillet with Kt = 1.3 and cycles between σmax = 170 MPa and σmin = −70 MPa. Find the Goodman safety factor.
L1 σm = (170 + (−70))/2 = 50 MPa
L2 σa = (170 − (−70))/2 = 120 MPa
L3 Sn = 0.5 × Su = 0.5 × 620 = 310 MPa
L4 S′n = Sn × CR = 310 × 0.81 = 251 MPa
L5 Apply stress concentration to mean stress:  σm,eff = Kt·σm = 1.3 × 50 = 65 MPa
L6 Goodman:  1/N = σa/Su + σm,eff/S′n = 120/620 + 65/251 = 0.453
L7 N = 0.45 < 1  →  the part FAILS in fatigue
L8 Recommendation: increase the section size or select a stronger alloy.
All 4 errors found. Corrected solution: S′n = 310 × 0.85 × 0.81 = 213 MPa; σa,eff = 1.3 × 120 = 156 MPa; 1/N = 156/213 + 50/620 = 0.813 → N = 1.23. The part actually passes — marginally. Note how three of the four errors each individually flipped or distorted the verdict: fatigue analysis is a chain, and every link matters.
Review habits worth stealing: (1) check every Marin-type factor is present before trusting S′n; (2) Kt (as Kf) multiplies the alternating component; (3) Goodman pairs σa↔S′n and σm↔Su; (4) 1/N is not N. Two minutes of this checklist would have saved this submission.
