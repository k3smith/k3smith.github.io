# Seg-labeler

GitHub Pages app for DocGraph **section span** gold labels.

**Live:** https://k3smith.github.io/seg-labeler/  
**Round:** `section_model_v2` — mark header / body / skip **spans** inside each unit.

## Fresh start (v2)

1. Create a **new** Google Sheet (do not reuse v1 labels).
2. Paste [`apps_script/Code.gs`](apps_script/Code.gs) → run `ensureHeader` → Deploy → Web app (Anyone).
3. Put the web-app URL in [`config.js`](config.js) → `sheetWebAppUrl` and push.
4. Hard-refresh the site.

Until the Sheet URL is set, labels save to localStorage + CSV download.
