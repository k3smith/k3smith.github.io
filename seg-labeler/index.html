Instructions (about 2 minutes)

You will see one text unit from a Navy / regulatory PDF (with a little context). Decide whether it is a section header or body under a header — the product graph model used by DocGraph.

header A section / subsection title, usually numbered (3.2.1, 2. REFERENCES, lettered chapter heads). The title of a section, not its body prose.
body Paragraph or text chunk that belongs under a header. Parent is the open section header — never another body line.
skip Running header/footer, page date (07 Nov 2023), TOC noise, blank/junk — not a graph unit.

If header: set its section number (if any) and choose its parent header from the list (or root). Prefills are model suggestions — correct them when wrong. If body: pick the section header it belongs under. Use the same initials when you return. Each unit is labeled by up to two people.
