Instructions (about 2 minutes)

You will see one text block from a Navy / regulatory PDF (with a little context above and below). Decide what kind of chunk unit it is and which section it belongs to - so an automated system can cite document, section, page, and quote correctly.

requirement Obligation language (shall, must, numbered requirement). Prefer this for nested sub-requirements.
definition Defines a term ("means", "DEFINITION", glossary-style).
reference Citation to another standard, CFR, NSI, or document list entry.
scope Title / purpose / applicability of an item or chapter.
note NOTES section, guidance, or non-binding commentary.
table Tabular content (or a clear table caption/row blob).
paragraph Ordinary body prose that is still a citeable unit.
skip Running header/footer, TOC noise, blank/junk, or not a chunk unit.

Prefill fields are suggestions only - correct them when wrong. For nested requirements, set parent section and must not split with so parent/child stay in one chunk. Use the same name/initials when you return. Each block is labeled by up to two people.
